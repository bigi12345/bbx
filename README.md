# ⭐ BB星 · 每日作业完成打卡系统

家长 / 孩子双端 · 手机 / 平板 / 电脑自适应 · 九宫格手势密码登录 · AI 拍照判题 · 星星能量条可视化

## 功能亮点
- 👨‍👩‍👧 **账号体系**：仅家长可注册主账号，单个家长最多创建 5 个孩子账号；孩子用「九宫格连线密码」登录（无文字密码），忘记由家长后台重置。
- 📚 **6 项打卡**：语文 / 数学 / 英语 / 英语单词（必做，每项 2 分）+ 阅读 / 体育（选做，+1 分），每日满分 10 分，自然日自动重置。
- 🤖 **AI 判题**：仅必做项，拍照 / 相册上传后识别对错并叠加 √/× 标记（未配置真实接口时启用内置演示识别；可在家长设置配置 OpenAI 兼容视觉接口）。**AI 仅供参考，绝不参与计分。**
- ⭐ **星星 + 能量条**：10 颗星星随得分点亮，马卡龙彩色能量条直观展示完成度；支持累计星星 / 连续打卡天数（仅个人纵向成长，无排行榜，规避攀比）。
- 💬 **家长评语**：每天一条整体评语，60 秒内多次编辑只推送一次提醒（可关闭）；可设置 AI 对错标记仅家长端可见，保护孩子自信。
- 🔒 **儿童友好与防误触**：选做项「今日无打卡内容」二次确认；九宫格「首点提示」开关降低重置负担；图片画质容错；单科多图数量上限保护体验。

## 本地运行
```bash
node server.js          # 默认 http://localhost:3000
```
要求 Node >= 18，零第三方依赖。家长注册后即可创建孩子账号、设置手势密码。

## 部署（Render 免费版 / 任意 Node 主机）
仓库根目录已含 `render.yaml`（Blueprint）。在 Render 新建 **Web Service** 关联本仓库即可自动识别并部署；
可选环境变量 `AI_API_URL` / `AI_API_KEY` / `AI_MODEL` 启用真实 AI 判题。
> ⚠️ 注意：Render 免费版磁盘非持久，服务休眠 / 重新部署可能清空账号与图片数据。长期稳定使用建议升级持久盘，或在家长端「设置」里配置对象存储与图片生命周期清理。

## 目录结构
- `server.js` — 零依赖 Node 后端（JSON 文件库 + 图片本地存储 + API + 静态服务）
- `public/` — 前端（马卡龙浅蓝 UI，自适应横竖屏）
- `public/js/shared.js` — 前后端共享计分逻辑
- `public/js/engine-local.js` — 纯静态部署时的本地演示引擎（无后端时降级使用）
- `selftest.js` / `test-local.js` — 端到端 / 同构性自查脚本

## 自查
```bash
node server.js &          # 启动后端
node selftest.js          # 后端 API 端到端自查
node test-local.js        # 本地演示引擎同构性自查
```
